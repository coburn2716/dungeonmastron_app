What it’s made of

The Dungeon Mastron Console is a DIY build made from accessible parts and simple electronics.

  • A 3D-printed enclosure
  • Physical buttons and LEDs for tactile input and feedback
  • A Raspberry Pi at the core
  • Official Raspberry Pi 7'' Screen
  • Plus basic electronic parts

No custom chips, no locked-down hardware, everything is understandable and replaceable.

Same Games, Everywhere

One game format. Two ways to play.

Every Dungeon Mastron game works the same way on both the physical console and the web player.

  • Build once
  • Play instantly in the web player
  • Load the exact same game onto the physical console

The platform doesn’t fork or downgrade experiences. The difference is not what you play, it’s how it feels to play.

The System Image

Dungeon Mastron provides a complete, ready-to-use system image.

  • Download a single IMG file
  • Flash it to an SD card
  • Insert it into the Pi and power on

No manual setup, no operating system configuration, no guesswork. The console boots directly into Dungeon Mastron.

Open Source & Community Beta

The Dungeon Mastron console is an open-source DIY project in active beta. All hardware designs, the system image, and the Python runtime are freely available on GitHub. Build one, remix it, improve it — and share feedback so we can make it better together.

Cartridge

One story. One cartridge

A complete world, made physical.

Built for creators

Every game you create can live on its own cartridge.

  • 3D-printed cartridges, designed to be reused and re-labeled
  • Each cartridge houses a USB drive that holds the complete game
  • One adventure per cartridge
  • Easy to swap, store, and share
  • Works on any Dungeon Mastron console

The same game file that runs in the web player can be loaded onto a cartridge without modification.
