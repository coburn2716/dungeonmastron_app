# 🎨 VISUAL STYLE EXAMPLES

## What is a Visual Style?

The **Visual Style** is the fixed prefix that appears in EVERY image prompt for your game. It ensures visual consistency across all generated images.

---

## HORROR GAMES

### Gothic Horror Watercolor
```
Gothic watercolor painting, wide cinematic composition, bleeding colors, 
cold tones with deep purples and blacks, diffused candlelight. A pale figure 
in Victorian clothing, consistent character silhouette, melancholic atmosphere, 
painterly bleeding edges, no explicit violence.
```
**Best for:** Victorian horror, ghost stories, literary horror  
**Color palette:** Deep purples, blacks, cold blues, warm candlelight  
**Mood:** Haunting, melancholic, ethereal

### Pixel Art Horror
```
Detailed 16-bit pixel art horror, 16:9 aspect ratio, limited color palette 
with deep shadows, dramatic lighting from single sources. A hooded protagonist, 
consistent sprite design, retro game aesthetic, ominous atmosphere, 
Castlevania-inspired.
```
**Best for:** Retro horror games, dungeon crawlers, metroidvanias  
**Color palette:** Limited 8–16 colors, deep blacks, accent reds  
**Mood:** Ominous, nostalgic, tense

### Ink Wash Horror
```
Japanese ink wash painting (sumi-e), horizontal scroll format, minimal colors 
with black ink and subtle reds, stark contrast lighting. A lone traveler 
silhouette, consistent figure design, atmospheric horror, traditional brush 
technique, no gore.
```
**Best for:** Folklore horror, minimalist horror, mythic tales  
**Color palette:** Black ink, paper white, restrained red accents  
**Mood:** Quiet dread, austere, contemplative


**Color palette:** Neutral grays, soft blues, natural tones

## CUSTOM TEMPLATE

Use this structure to create new Visual styles:

```
[STYLE], [FORMAT], [TECHNIQUE], [COLOR PALETTE], [LIGHTING].
[CHARACTER DESCRIPTION], consistent character design, [MOOD], [CONSTRAINTS].
```

**Example custom creation:**
```
Charcoal sketch on cream paper, wide format, rough expressive strokes, 
limited grayscale with sepia highlights, diffused natural light. A wandering 
scholar with glasses and satchel, consistent character design, contemplative 
atmosphere, hand-drawn aesthetic, no violence.
```
