# 🎬 Dungeon Mastron Animation Generator

Generate smooth Ken Burns style video animations for your Dungeon Mastron games!

## Quick Start

### 1. Prerequisites

**Install FFmpeg:**
```bash
# Mac
brew install ffmpeg

# Linux (Ubuntu/Debian)
sudo apt install ffmpeg

# Windows
# Download from https://ffmpeg.org/
```

### 2. Prepare Your Game

```bash
your_game/
├── animation_manifest.json   # Generated by game builder
└── images/
    ├── page_001.jpg          # Your source images
    ├── page_002.jpg
    └── ...
```

### 3. Generate Animations

```bash
cd your_game/
python animation_generator.py
```

That's it! Videos will be created in `images/animations/` folder.

---

## What It Does

- Reads `animation_manifest.json` from game builder
- For each page:
  - Loads source image from `images/`
  - Applies Ken Burns effect (zoom + pan)
  - Saves video to `images/animations/`
- Takes ~2 seconds per video
- Creates smooth 30 FPS H.264 videos

---

## Animation Effects

The generator supports 10 cinematic effects:

| Effect | Description |
|--------|-------------|
| 🎲 **Random** | Picks random effect |
| 🔍 **Zoom In** | Subtle zoom 100% → 115% |
| 🔎 **Zoom Out** | Reverse zoom 115% → 100% |
| ⬆️ **Zoom + Pan Up** | Zoom while drifting up |
| ↗️ **Zoom + Pan Up-Right** | Diagonal movement |
| ➡️ **Zoom + Pan Right** | Drift right |
| ↘️ **Zoom + Pan Down-Right** | Diagonal movement |
| ⬇️ **Zoom + Pan Down** | Drift down |
| ↙️ **Zoom + Pan Down-Left** | Diagonal movement |
| ⬅️ **Zoom + Pan Left** | Drift left |
| ↖️ **Zoom + Pan Up-Left** | Diagonal movement |

## Technical Specs

**Video Format:**
- Resolution: 1280x720 (landscape)
- Duration: 7 seconds
- Frame rate: 30 FPS
- Codec: H.264 (libx264)
- Quality: CRF 23
- File size: ~1-2 MB per video

**Ken Burns Settings:**
- Zoom range: 100% → 115% (subtle)
- Pan speed: 2-4 pixels/frame (slow)
- Smooth easing curve

## Troubleshooting

### FFmpeg Not Found

```bash
# Verify installation
ffmpeg -version

# If not found, install:
brew install ffmpeg  # Mac
sudo apt install ffmpeg  # Linux
```

### Source Images Missing

```bash
# Check images exist
ls images/page_001.jpg

# Verify manifest references correct files
cat animation_manifest.json
```

### Videos Too Large

Edit `animation_generator.py` line with CRF value:
```python
'-crf', '23',  # Try 28 for smaller files
```

## Advanced Usage

### Custom Game Folder

```bash
python animation_generator.py
# Looks for animation_manifest.json in current directory
```

### Regenerate Single Page

Delete the video and run again:
```bash
rm images/animations/page_005.mp4
python animation_generator.py
# Only regenerates missing videos
```

### Check Generated Videos

```bash
# List all videos
ls -lh images/animations/

# Play a video (Mac)
open images/animations/page_001.mp4

# Check video info
ffprobe images/animations/page_001.mp4
```
