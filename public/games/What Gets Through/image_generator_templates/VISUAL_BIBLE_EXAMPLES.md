# 🎨 VISUAL BIBLE EXAMPLES

## What is a Visual Bible?

The **Visual Bible** is the fixed prefix that appears in EVERY image prompt for your game. It ensures visual consistency across all generated images.

**Format:**
```
[STYLE], [FORMAT], [TECHNIQUE], [COLOR PALETTE], [LIGHTING]. 
[CHARACTER DESCRIPTION], consistent character design, [MOOD], [CONSTRAINTS].
```

## CUSTOM TEMPLATE

If you want to create your own Visual Bible, use this structure:

```
[Choose art style: watercolor/pixel art/oil painting/digital/etc.],
[Choose format: cinematic 16:9/square/vertical/panoramic],
[Choose technique: brushstrokes/clean lines/textured/smooth],
[Choose color palette: muted/vibrant/limited/monochrome + specific colors],
[Choose lighting: moody/bright/dramatic/soft + light source].

[Describe main character: appearance, clothing, distinctive features],
consistent character design,
[Choose mood: atmospheric/tense/peaceful/energetic],
[Add constraints: no gore/family-friendly/realistic/stylized].
```

**Example custom creation:**
```
Charcoal sketch on cream paper, wide format, rough expressive strokes, 
limited grayscale with sepia highlights, diffused natural light. A wandering 
scholar with glasses and satchel, consistent character design, contemplative 
atmosphere, hand-drawn aesthetic, no violence.
```

## TIPS FOR CHOOSING

**Match your game's tone:**
- Horror → Muted colors, moody lighting, subtle threats
- Fantasy → Rich colors, dramatic lighting, epic scale
- Sci-Fi → Clean/neon aesthetics, tech details, isolation
- Mystery → High contrast, shadows, film noir

**Consider your audience:**
- Kids → Bright, friendly, clear
- Teens → Stylized, energetic, bold
- Adults → Realistic, nuanced, atmospheric
- All ages → Balance accessibility with depth

**Think about production:**
- Pixel art → Easier to maintain consistency
- Painted styles → More artistic but harder to match
- Photorealistic → Very difficult to keep consistent
- Stylized → Sweet spot for AI generation

**Technical considerations:**
- AI is better at: Specific art styles (Ghibli, pixel art, oil painting)
- AI struggles with: Made-up styles, vague descriptions
- Always specify: Character consistency, format, color palette

## USING YOUR VISUAL BIBLE

Once you choose or create your Visual Bible:

1. Copy it exactly
2. Paste it into the Image Prompt Generator template
3. Use it as the prefix for EVERY prompt
4. Never modify it mid-project
5. If you need changes, regenerate ALL prompts

**Consistency is everything!**
